Resize Images to a Target File Size

UtilityCanvas helps you reduce images toward a target file size such as 20KB, 50KB, 100KB, 200KB or 500KB.

How to resize an image to a specific KB size

  • Choose a JPG, PNG or WebP image.
  • Select or enter your target file size.
  • Choose JPG or WebP output.
  • Click Resize to Target KB.
  • Download the processed image.

Private browser-based processing

Your image is processed directly inside your browser. The image does not need to be uploaded to a server.

Supported target sizes

The tool supports 20KB, 50KB, 100KB, 200KB and 500KB presets, as well as custom target sizes.
