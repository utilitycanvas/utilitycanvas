UtilityCanvas is a collection of practical online tools for images, YouTube creators and social media content.

Browser-based image processing

Our image tools are designed to process files directly in your browser whenever possible. This means your selected image does not need to be uploaded to a remote server for basic image processing.

Simple tools without unnecessary steps

Choose a tool, select your image, choose the required settings and download the result. UtilityCanvas is designed to keep common image tasks simple and accessible.

Image compression and resizing tools

UtilityCanvas provides free browser-based tools to compress, resize, crop and convert images. You can reduce image file sizes, change image dimensions and prepare images for websites, social media, documents and online uploads.

Common image tasks

  • Compress JPG, PNG and WebP images to reduce file size.
  • Resize images to specific width and height dimensions.
  • Compress images to a target file size such as 50KB or 100KB.
  • Crop images to common aspect ratios and sizes.
  • Convert images between supported formats.
